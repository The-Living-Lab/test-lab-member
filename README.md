# The Diplomatic Sandbox

Create a minimal starter app titled "Tribute & Treaty". Only a single placeholder home page that says "Tribute & Treaty — setting up" in Helvetica on a dark background. Do not build any features, do not add authentication screens, and do not add or use the Lovable AI connector. All game code will be pushed later from GitHub by another developer, so keep the starter as small as possible.

This project was built with [Lovable](https://lovable.dev).

**Live app**: https://diplomatic-sandbox.lovable.app

## Build with Lovable

Continue developing this project in the [Lovable editor](https://lovable.dev/projects/fb9e9630-872b-4cc5-8267-4e97835c25cd).

## Development

Prefer working locally? You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
